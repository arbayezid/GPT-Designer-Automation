# Product Requirements Document (PRD)
**Product Name:** ChatGPT Auto-Prompter & Drive Sync Extension (Name TBD)
**Document Status:** Draft v1.0
**Platform:** Google Chrome Extension (Manifest V3)

## 1. Product Overview
### 1.1 Objective
To develop a Google Chrome extension that automates a multi-step prompt workflow in ChatGPT. The extension will pull reference images and a sequence of text prompts (from an Excel file) from Google Drive, feed them into ChatGPT, extract the generated images, and save them back to Google Drive in an organized structure.

### 1.2 Target Audience
UI/UX Designers, AI Artists, and Prompt Engineers who need to generate bulk variations of design concepts using ChatGPT without manually copying, pasting, and downloading files.

---

## 2. Core User Workflow
1. **Initialization:** The user sets up the Google Drive folder IDs (INPUT and OUTPUT) in the extension settings.
2. **Fetch Data:** The extension reads the `INPUT` folder. It looks for a specific `SET` folder (e.g., `SET-1`).
3. **Analyze Set:** Inside `SET-1`, it identifies:
    *   A batch of reference images (e.g., screenshots of an app).
    *   An Excel (.xlsx or .csv) file containing a sequenced list of prompts.
4. **Begin Chat Thread:** The extension opens ChatGPT, creates a new chat thread (1 Thread = 1 Set).
5. **Initial Injection:** It uploads all the reference images from `SET-1` to the ChatGPT prompt box.
6. **Execution Loop:**
    *   **Send:** The extension reads Prompt #1 from the Excel sheet and sends it to ChatGPT alongside the images.
    *   **Wait:** The extension waits for ChatGPT to finish generating the response/images.
    *   **Extract:** It scrapes/downloads the generated image files from the ChatGPT response.
    *   **Save:** It uploads these generated images to the Google Drive `OUTPUT` folder, nested under `SET-1/Prompt-1/`.
    *   **Next:** It reads Prompt #2 from the Excel sheet, sends it to the *same* chat thread, waits, extracts, and saves to `SET-1/Prompt-2/`.
7. **Completion:** The loop continues until all prompts in the Excel file are exhausted.

## 3. Functional Requirements

### 3.1 Google Drive Integration
*   **Authentication:** The extension must authenticate the user's Google account via OAuth 2.0 to access Drive.
*   **Targeting Folders:** The extension must use specific Google Drive Folder IDs (provided by the user) to locate the `INPUT` and `OUTPUT` directories.
*   **File Reading:** 
    *   Must be able to read and download image files (.jpg, .png, etc.) from Drive.
    *   Must be able to parse Excel/CSV files to extract prompt text sequentially.
*   **File Writing:** Must be able to create new sub-folders in the `OUTPUT` directory and upload downloaded ChatGPT images to them.

### 3.2 ChatGPT Automation (DOM Manipulation)
*   **Chat Injection:** The extension must programmatically interact with the ChatGPT web UI to:
    *   Attach/upload image files.
    *   Input text into the prompt text area.
    *   Click the "Send" button.
*   **Response Handling:**
    *   Must detect when ChatGPT is actively generating a response and when it has finished (e.g., waiting for the "Stop generating" button to disappear).
    *   Must extract the image URLs/files generated by DALL-E 3 within the ChatGPT chat interface.

### 3.3 Folder & File Mapping Logic
The system must maintain strict adherence to folder mapping between Input and Output.
*   **Input Structure:** `Drive Input ID` -> `SET-X` -> `[Images + 1 Excel File]`
*   **Output Structure:** `Drive Output ID` -> `SET-X` -> `Prompt-Y` -> `[Generated Images]`

---

## 4. User Interface (Extension Popup)
The Chrome extension popup should be minimal and functional.
*   **Settings Tab:** Input fields for `Google Drive INPUT Folder ID` and `Google Drive OUTPUT Folder ID`.
*   **Action Tab:** 
    *   A "Start Automation" button.
    *   A dropdown to select which "SET" to process (or an option to process all sets sequentially).
*   **Status Indicator:** A live log showing what the extension is currently doing (e.g., *"Reading Set 1"*, *"Sending Prompt 3/10"*, *"Uploading outputs to Drive"*).

## 5. Technical Architecture & Constraints

### 5.1 Tech Stack
*   **Frontend:** HTML/CSS/JavaScript (Chrome Extension Manifest V3).
*   **APIs:** Google Drive API v3 (for file reading/writing), SheetJS (or similar library to parse Excel files inside the browser).
*   **Content Scripts:** JavaScript injected into `chatgpt.com` to manipulate the DOM.

### 5.2 Technical Risks & Mitigation
*   **ChatGPT UI Updates:** *High Risk.* Because OpenAI does not provide an official API for the Web UI, the extension must rely on DOM selectors (HTML classes/IDs). If OpenAI updates their website code, the extension will break. 
    *   *Mitigation:* Build the DOM selectors dynamically or store them in an external config file so they can be updated without resubmitting the extension to the Chrome Web Store.
*   **Rate Limits:** ChatGPT limits how many messages/images can be generated per hour (especially for GPT-4/DALL-E 3).
    *   *Mitigation:* The extension must be able to detect rate limit error messages ("You've reached your limit... try again in X minutes") and automatically pause the sequence, resuming when the time limit expires.
*   **Upload/Download Speeds:** Large images may take time to upload to ChatGPT and Drive.
    *   *Mitigation:* Implement robust `async/await` logic to ensure the next prompt is not sent until the previous batch is fully uploaded to Drive.
